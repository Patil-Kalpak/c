Syntax Directed Translation (SDT/SDD)
Uses semantic rules with grammar productions
Computes value during parsing
Meaning of $$ , $1 , $3
$$ = result of production
$1 = first symbol value
$3 = third symbol value

Example:

E→E+T{$$=$1+$3}
